News fragments
==============

Add one fragment per pull request in this directory. The file name should follow
``<issue>.<type>.rst`` where ``<issue>`` is the GitHub issue or PR number and
``<type>`` is one of ``feature``, ``bugfix``, ``doc``, ``removal`` or ``misc``.

A PR that is not user-visible can be exempted with the ``no-news-required``
label.
